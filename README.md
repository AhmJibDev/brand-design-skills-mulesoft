# brand-design-skills-mulesoft

Claude skills for producing on-brand MuleSoft / Salesforce visual deliverables.

| Skill | Description |
|---|---|
| [`mulesoft-brand`](mulesoft-brand/SKILL.md) | Official MuleSoft / Salesforce 2026 brand guidelines (colors, typography, visual direction) for any visual or content deliverable. |
| [`html-slide-deck`](html-slide-deck/SKILL.md) | Polished, animated, single-file HTML slide deck (keyboard/click navigation, fragment reveals, inline SVG diagrams, fullscreen, jump menu). Pair with `mulesoft-brand`. |

## Installation

Copy the skill folders into your skills directory (e.g. `~/.claude/skills/`).
